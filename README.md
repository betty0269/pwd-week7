
# Ajou FoodMap API - Week 7

TypeScript, Express, Supabase PostgreSQL을 이용한 맛집 API 서버입니다.

## 주요 기능

- 맛집 목록 조회
- 맛집 상세 조회
- 인기 맛집 조회
- 새로운 맛집 등록
- Supabase PostgreSQL 데이터 영구 저장

## 실행 방법

1. npm ci --include=dev
2. .env 파일에 Supabase 환경변수 설정
3. npm run dev

## 검사

- npm run typecheck
- npm test
- npm run build

## 환경변수

.env.example 파일을 참고합니다.
실제 Secret key는 GitHub에 업로드하지 않습니다.
